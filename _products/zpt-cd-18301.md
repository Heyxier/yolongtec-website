# ZPT-CD-18301 18V 30Nm Drill Driver

The ZPT-CD-18301 is a entry-level 18v professional drill driver. Delivering 30 N·m of torque, it provides reliable performance for 18V cordless power tool applications.

- **Two-speed gearbox for versatile operation**
- **Auto spindle lock for quick bit changes**
- **10mm single sleeve metal keyless chuck**
- **Variable speed with reverse function**
- **LED work light for dark workspaces**
- **Rubber over-mould grip for comfortable handling**
