# ZPT-CD-12502 12V 50Nm Brushless Drill & Driver 2in1

The ZPT-CD-12502 is a multi-function design, two tools in one — drill and driver. Featuring a brushless motor delivering 50 N·m of torque, it provides reliable performance for 12V cordless power tool applications.

## Key Features

- **Brushless motor for higher efficiency and longer life**
- **Drill and driver 2in1 with detachable chuck**
- **Two-speed gearbox for versatile operation**
- **Auto spindle lock for quick bit changes**
- **10mm single sleeve keyless chuck**
- **Variable speed with reverse function**
- **LED work light for dark workspaces**
- **Battery capacity indicator**
